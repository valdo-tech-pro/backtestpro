# BacktestPro

**Test Your Strategy. Master Your Trading.**

BacktestPro is a web-based trading strategy research platform for Forex, Gold and other metals, indices, and cryptocurrency.

## Planned features

- Interactive market charts
- Historical candle replay
- Manual trade simulation
- Strategy testing and performance analytics
- Trading journal

## Initial technology plan

- React, TypeScript, and Vite
- TradingView Lightweight Charts
- Supabase for authentication and data storage (planned)
- Vercel for deployment

## Project status

Early development. Market data integrations and automated strategy execution are not yet implemented.
